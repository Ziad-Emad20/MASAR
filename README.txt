 MASAR

MASAR is a project developed by [Ziad-Emad20](https://github.com/Ziad-Emad20). The repository contains various web development resources, including HTML, JavaScript, and CSS files.

 Project Structure

The repository includes the following directories and files:

- Css/: Contains SCSS files for styling.
- assetsPage/: Directory for asset-related pages.
- img/: Contains image assets used in the project.
- js/: JavaScript files for interactive functionalities.
- src/: Source files for the project.
- webfonts/: Web font files used in the project.
- index.html: The main HTML file.
- package.json: Contains project metadata and dependencies.
- promotion (1).png: Promotional image related to the project.

## Technologies Used

- JavaScript: Adds interactivity to the web pages.
- HTML: Structure of the web pages.
- CSS: Styling of the web pages.
